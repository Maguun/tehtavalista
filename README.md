# Tehtävälista - ToDo-sovellus

Yksinkertainen verkkosovellus, jolla käyttäjä voi lisätä, merkitä valmiiksi ja poistaa tehtäviä.

## Projektin määrittely ja dokumentaatio

Lue [projektin määrittely ja hyväksymiskriteerit](docs/01-projektikuvaus.md).

## Kokeile sovellusta

Sovellus toimii selaimessa:

https://maguun.github.io/tehtavalista/

Sovellusta voi käyttää myös lataamalla projektin GitHubista ja avaamalla `index.html`-tiedoston selaimessa.

## Ominaisuudet

- Tehtävien lisääminen ja poistaminen
- Tehtävien merkitseminen valmiiksi
- Tehtävien tallentaminen selaimeen
- Tyhjien tehtävien lisäämisen estäminen

## Käytetyt teknologiat

- HTML – rakenne
- CSS – ulkoasu
- JavaScript – toiminnallisuus
- localStorage – tietojen tallennus

Sovellus ei vaadi kirjautumista, tietokantaa tai erillistä palvelinta.

## Testaus

Sovellukselle suoritettiin kahdeksan testiä, jotka kaikki hyväksyttiin.

Testaus voidaan toistaa käyttämällä sovellusta selaimessa ja seuraamalla testausdokumentin testitapauksia.

## Tunnetut rajoitukset

Tehtävät tallentuvat vain käytettävään selaimeen. Ne eivät siirry automaattisesti toiselle laitteelle. Selaimen paikallisten tietojen poistaminen voi hävittää tehtävät.
